Camera controls

One finger pans. Pinch begins only after a real second finger touches the canvas. Tap empty space to deselect. Hold an event first, then drag, to move it.

Chronology

Physical height is time. Higher = later. Lower = earlier. Event movement snaps to chronology levels.

Creating events

Continue extends the end of a path. Insert Event places something inside an existing connection. New Branch deliberately creates another path from an event that already continues. There is no Before command.

Mobile layout

Global maintenance actions live under the top •••. The bottom dock always contains Big Bang, Selected, and Fit Web.

Undo / Redo

Story changes are remembered for up to 100 actions. Camera pan and zoom are intentionally not included in history.

Live timeline

Dragging an event now updates only that event and its connected lines on each display frame. A solid core stays beneath the cosmic glow.

Performance engine

While you pan, pinch, drag, or coast, Nulliverse temporarily simplifies expensive glow, blur, and shadow effects and updates the camera at most once per display frame. Full cosmic effects return when motion stops.

Dawns

First Dawn is the starting chapter. Later Dawns do not exist until you create them. Select the event where a chapter should end, then use Begin Next Dawn. Nulliverse never pre-places future chapters for you.

Time of day

Time is descriptive metadata only: Unspecified, Approximate, or Exact. Approximate time uses Dawn/Morning/Afternoon/Evening/Night. Choosing a time never moves an event, and moving an event never changes its chosen time. Only crossing a Dawn boundary changes which Dawn/chapter it belongs to.

Time display

Time-of-day stays on the event itself through its time chip. The large Dawn/Morning/Afternoon/Evening/Night background bands and elastic band layout are intentionally not used in this version.

The web

Cosmic threads are the cytoskeleton of your story universe. Simple deleted in-between events now heal the thread automatically.
